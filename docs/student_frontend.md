# Student role Sidebar Menu Modules and Contents

## Student Dashboard

Purpose: Provide a quick overview of the student's attendance status.

### Contents:

    Summary Cards
    - Attendance Rate (%)
    - Present Days
    - Late Count
    - Absences
    - Excused Absences

    Today's Attendance
    - Date
    - Time In
    - Attendance Status
    - Attendance Method (RFID / QR)

    Recent Notifications
    - Attendance marked successfully
    - Late notification
    - Absence notification
    - Excuse slip status

    Quick Actions
    - View Attendance
    - Submit Excuse Slip
    - View Attendance Calendar

## My Attendance

Purpose: View personal attendance records.

### Contents:

    Attendance Records

        Columns
        - Date
        - Subject
        - Teacher
        - Time In
        - Status
        - Attendance Method
        - Remarks

    Functions
    - Search by Date
    - Filter by Subject
    - Filter by Month
    - View Attendance Details

    Attendance Summary

        Displays
        - Total Present
        - Total Late
        - Total Absent
        - Total Excused
        - Attendance Percentage

## RFID/QR Code

Purpose: Manage the student's RFID card and QR code.

### Contents:

    RFID Information

        Displays
        - RFID Card Number
        - Card Status
        - Registration Date

    My QR Code

        Displays
        - Personal QR Code
        - Student ID
        - Name

    Functions
    - View QR Code
    - Download QR Code
    - Print QR Code
    - Report Lost RFID (optional)

    Note: Students should only view their QR code. RFID registration or replacement is handled by the Admin.

## Attendance Calendar

Purpose: View attendance history in calendar format.

### Contents:

    Calendar

        Each day is color-coded:
        - ✅ Present
        - 🟡 Late
        - 🔴 Absent
        - 🔵 Excused

        Clicking a date displays:
        - Subject
        - Teacher
        - Time In
        - Attendance Status
        - Remarks

    Filters
    - Month
    - Semester

### Contents:

        - Reason
        - Supporting Document (PDF/Image)
        - Additional Remarks

    Functions
    - Submit Excuse Slip
    - Upload Attachment
    - Cancel Submission

    My Excuse Slips

        Columns
        - Date Submitted
        - Absence Date
        - Subject
        - Status
        - Teacher Remarks

## Perfect Attendance Status

Purpose: Let students monitor their eligibility for attendance awards.

### Contents:

    Displays
