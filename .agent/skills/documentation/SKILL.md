# Documentation Skill

## Writing Style

Use formal academic English unless Tagalog is requested.

Write clearly for:

* Capstone manuscript
* Technical documentation
* System proposal
* Module explanation

## Documentation Structure

Include when applicable:

1. Introduction
2. Purpose
3. Scope
4. Actors
5. Functional Process
6. System Workflow
7. Technical Implementation
8. Database Interaction
9. Security Considerations
10. Limitations
11. Future Enhancement

## Important

Do not invent features.

Use only confirmed project information.

Clearly mark assumptions separately.
