# Architecture Skill

## Goal

Design maintainable architecture using HTML, Tailwind CSS, JavaScript, and Supabase.

## Responsibilities

Analyze:

* Module interaction
* Page navigation
* JavaScript responsibilities
* Database interaction
* Role separation
* Security boundaries

## Workflow

1. Identify modules involved.
2. Describe responsibilities of each module.
3. Map frontend to JavaScript files.
4. Map JavaScript to Supabase tables.
5. Identify role permissions.
6. Identify data flow.
7. Identify future scalability considerations.

## Output

Always include:

* Architecture overview
* Module responsibilities
* Data flow
* Folder mapping
* Security considerations
* Scalability recommendations

Do not generate unnecessary code unless requested.
