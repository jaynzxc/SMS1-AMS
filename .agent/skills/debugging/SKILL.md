# Debugging Skill

## Goal

Find the root cause before modifying code.

## Process

### 1. Reproduce

Identify:

* Expected behavior
* Actual behavior
* Error message
* Affected page

### 2. Inspect

Check:

* HTML
* Tailwind classes
* JavaScript
* Console errors
* Supabase requests

### 3. Root Cause

Explain exactly why the issue occurs.

### 4. Minimal Fix

Modify only necessary files.

### 5. Regression Check

Verify related modules are unaffected.

## Response Format

Always provide:

* Problem
* Root Cause
* Evidence
* Fix
* Files Modified
* Testing Steps
