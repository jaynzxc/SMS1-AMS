# Planning Skill

## Goal

Produce a complete implementation plan before development.

This skill is for planning only.

Do not write production code unless explicitly requested.

## Workflow

### Step 1 — Understand the request

Identify:

* Module name
* Users involved
* Main purpose
* Required features
* Existing related modules

### Step 2 — Analyze dependencies

Check whether the feature affects:

* Admin
* Student
* Teacher
* RFID
* QR
* Attendance
* Reports
* Analytics
* Authentication
* RBAC

### Step 3 — Produce workflow

Create:

1. User workflow
2. System workflow
3. Data flow
4. Validation flow

### Step 4 — Break into development tasks

Divide into:

* Frontend
* JavaScript
* Supabase
* Testing

### Step 5 — Identify risks

Mention:

* Missing requirements
* Security concerns
* Database impact
* Possible regression

## Required Output Format

Always return:

1. Feature Overview
2. Objectives
3. Actors
4. Functional Requirements
5. Workflow
6. Development Plan
7. Database Impact
8. Testing Checklist
9. Assumptions
10. Questions for Client
